# Specifications

Accepted behavior and quality requirements live in feature areas below. IDs use a registered uppercase prefix and append-only zero-padded serial; each requirement declares current conformance (`conforming`, `pending` or `divergent`), planned verification and evidence. Optional Gaps contain unaccepted candidates, not unfinished accepted requirements. Deprecated IDs remain claimed and are never reused.
